## 🎯 KPSSODAK Nedir?

**KPSSODAK**, kamu personeli seçme sınavlarına hazırlanan adaylar için baştan sona modern teknolojilerle geliştirilmiş **yeni nesil, akıllı bir sınav hazırlık platformudur.** 

Standart test kitaplarının ötesine geçerek; interaktif harita üzerinde coğrafya öğrenimi, tablet ve kalemle soru üzerinde işlem yapma, kişiselleştirilmiş eksik giderme algoritmaları ve oyunlaştırılmış çalışma serileri ile öğrenme verimini en üst seviyeye taşır.

> 📱 **Tek Ekosistem:** iOS (App Store), Android (Google Play), Web Yönetim Portalı ve Tanıtım Sitesi.

## 🛠️ Sistem Mimarisi & Altyapı

KPSSODAK, yüksek erişilebilirlik ve temiz kod prensipleriyle (Clean Architecture) tasarlanmış modern bir teknoloji yığınına sahiptir:

- **Backend:** .NET 9 Web API, Entity Framework Core 9, SQL Server, Clean Architecture
- **Mobil Uygulama:** React Native, Expo SDK, TypeScript, Expo Router, Reanimated
- **Web Yönetim Portalı:** React 19, Vite, TypeScript, Tailwind CSS
- **Tanıtım & Web Sitesi:** React, Vite (SEO & Performans odaklı)
- **Güvenlik & Doğrulama:** JWT Kimlik Doğrulama, Expo Secure Store, Apple Sign-In & Google Sign-In, IAP Mağaza Doğrulamaları
